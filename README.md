# Giovani Detector IPTV Bot

Bot para verificar e testar links M3U e domínios DNS.

## Como rodar localmente

1. Tenha o Python instalado.
2. Clone o repositório.
3. Instale os requisitos: `pip install -r requirements.txt`
4. Crie um arquivo `.env` com o seu `TELEGRAM_TOKEN` e `ADMIN_IDS` (o arquivo não vai pro GitHub por causa do .gitignore).
5. Rode o bot: `python bot.py`
